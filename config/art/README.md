# Menu art

Put one image per game here, named after the game's `id` in `config\games.json`: `<id>.png`.

The top part of each menu tile shows it: a dimmed, cropped copy fills the tile and the whole image sits on top, so
wide marquees and logos are never cut off. Tiles without art show only the text.

Images in this folder are ignored by git (`.gitignore`), so your own art stays out of the repository.
